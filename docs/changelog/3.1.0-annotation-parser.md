# Add the annotation parser

## What changed

- Added `Strukt\Annotation\Parser`
  (`src/Strukt/Annotation/Parser.php`), moved from `strukt/framework`'s
  `Strukt\Framework\Annotation\Parser`.
- Added `tests/Unit/ParserTest.php` covering class/property/method parsing,
  repeated-name merging, and `key=value` syntax, with self-contained fixtures.

## Why

The parser only needs PHP reflection and belongs with the package that already
documents "PHPDoc annotation utilities". Moving it here lets `strukt/generator`
own annotation parsing without depending on `strukt/framework`.

## Documentation

- `README.md`: added a `## Parser` section documenting the constructor,
  `getNotes()`, the annotation forms, and an example.

## Tests

- `tests/Unit/ParserTest.php` (3 cases). Generator suite: 9 passed.

## Public API impact

- **New:** `Strukt\Annotation\Parser` with the same `getNotes()` contract as the
  former `Strukt\Framework\Annotation\Parser`.
